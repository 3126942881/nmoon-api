# 小月神api 1.3.68 Windows 修复版

本地修复版，基于官方 Cockpit Tools v1.3.67 及已交付的定制版 1.3.67，不代表采用了官方 v1.3.68。

本次修复：

1. 关闭或切换“使用密钥”弹窗时使旧模型请求失效。迟到成功、失败和加载结束均不能覆盖当前 Key，离开页面时也会失效。
2. 供应商模型目录尊重显式列表和空列表。删除预设模型、清空模型和重命名后重新加载均保留用户设置；新供应商未指定目录时仍提供 GPT-6 默认预设，独立 Key 的目录保持独立。
3. GPT-6 Sol/Luna/Astra 使用 256000 上下文、230400 自动压缩阈值；GPT-6.1 Sol 使用 272000/244800。回归测试与打包的后端模型目录核对。
4. Claude Code 的 settings.json 与 Windows 环境变量命令同时写入所选 ANTHROPIC_MODEL。
5. 同时包含 GPT 与 Claude 等模型的 Key 可选择模型分组；模型下拉框和客户端配置随分组切换，避免混用模型与客户端模板。

针对上述问题新增的 7 个回归场景在修复前失败，修复后通过。完整测试、编译和安装包校验以交付目录的验证报告为准。

品牌、QQ 联系方式、旧站密钥隔离、关闭在线更新与远程推广、空公告及原作者声明沿用上版。此次仅构建 Windows x64 简体中文 EXE；保留旧版源码和安装包。未做真实本站 API 调用或覆盖安装。
