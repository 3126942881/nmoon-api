## 小月神api 1.3.80

- 升级到 Cockpit Tools v1.3.80，保留小月神api 品牌和定制功能。
- 网站及 API 默认域名更新为 `ai.lmgai.cn`，OpenAI 兼容地址为 `https://ai.lmgai.cn/v1`，Claude 地址为 `https://ai.lmgai.cn`。
- 合入 GPT-6.1 Terra、图片接口及上游账号切换和 API 稳定性更新。
- 保留模型目录保存、密钥隔离、请求竞态和客户端配置修复。模型实际可用性取决于对应账号和 API Key。
- 新增本仓库的签名更新渠道和 GitHub Actions 发布流程，由 3126942881 维护发布。
- 移除上游内置的 Google OAuth 客户端参数。Antigravity 的 Google 授权和令牌刷新需自行配置环境变量后使用。

### 安装与更新

Windows x64 用户下载 `NmoonAPI_1.3.80_windows-x64-setup.exe`。1.3.68 及更早的定制版关闭了在线更新，需要先手动安装本版；之后可在设置中检查本仓库的新版本。

默认不自动安装；已有用户的本地更新偏好会保留。已有供应商中手动保存的旧 API 地址请核对后修改为新地址。

附安装包 SHA-256 校验值和更新签名。更新签名不等同于 Windows 商业代码签名证书。
