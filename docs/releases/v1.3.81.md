## 小月神api 1.3.81

- 修复“额度查询失败：PROVIDER_USAGE_HTTP_404”问题：1.3.80 内置中转站配置残留旧域名，会覆盖页面默认的新域名；现在额度和模型查询均使用 `https://ai.lmgai.cn/v1`。
- 同步修正内置网站和注册链接，避免跳转到旧站点。
- 增加读取实际内置配置并执行页面查询的回归测试，防止默认值正确但运行时配置仍指向旧地址的问题再次出现。

### 更新

1.3.80 用户可在软件设置中检查更新；也可以下载安装 `NmoonAPI_1.3.81_windows-x64-setup.exe`。无需删除账号或重新创建 API Key。

本次修复的是软件请求地址。新站点的额度接口已验证存在，实际额度结果仍取决于 API Key 的有效性及权限。

### Mac 安装包

本版本已补充 Apple M 系列芯片和 Intel 两种 DMG 安装包，最低要求 macOS 12.0。打开 DMG 后将“小月神api”拖入“应用程序”；旧 Mac 1.3.58 用户需要手动安装此次新版。当前包使用 ad-hoc 签名，尚未经过苹果公证，详见 [Mac 安装说明](../NMOON-MACOS.md)。Mac 更新文件已加入更新清单，原有 Windows 更新条目保持不变。
